# CIS530 Week 8 API

## Swagger UI

1. Start the application:
   ```bash
   ./mvnw spring-boot:run
   ```
2. Open the Swagger UI in a browser:
   - http://localhost:8080/swagger-ui.html
3. Optional: view the raw OpenAPI document:
   - http://localhost:8080/v3/api-docs

This page lists the available Student API endpoints and includes request/response details for testing the application.
